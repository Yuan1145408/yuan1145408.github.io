收录标准

  • 公开可访问：仓库可匿名打开，非私有、非仅限组织内。
  • 真的是游戏：排除引擎、框架、脚手架、示例合集与素材库。
  • 浏览器可运行：有可直接访问的在线入口；或提供公开实例（需账号/自建会明确标注）。
  • 链接可用：2026-11-22 逐条做过 HTTP 探测，确认返回正常页面而不是首页跳转或错误页。
  • 授权清晰：仓库公开可见；本站只做索引，不复制、不托管游戏资源。

可用性怎么读

  • 站内试玩页面没有禁止嵌入，可以直接在站内打开。
  • 仅跳转对方设置了禁止嵌入的安全头，只能新窗口打开。
  • 需账号要先注册或登录才能进入游戏。
  • 需自建要自己部署服务或准备游戏文件。
  • 链接异常检测时不可达，已在详情里写明原因。

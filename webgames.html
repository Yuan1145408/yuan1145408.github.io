先读这段，能少踩很多坑

  • 本站不托管任何游戏本体。所有入口都指向官方平台或项目原页面，需要自备文件的条目请使用你自己购买的正版游戏。
  • 不要安装任何“启动器 / 扩展 / 插件”。浏览器移植只需要一个标签页，凡是要你装东西的页面直接关掉。
  • 标注「需自备游戏文件」的条目本质是“浏览器运行器 + 你的合法资源”，页面本身不含游戏内容。
  • 境外节点在国内可能需要代理，标了「境外节点」的平台如果打不开，优先试上面带「国内直连」的。

自己把游戏搬上网页，大概要这几步

  1. 拿源码。优先找反编译 / 源码移植项目（上面的「开源项目与源码」里都是），确认许可证允许你的用途。
  2. 装工具链。C/C++ 项目用 Emscripten 编译到 WebAssembly；自研项目直接用 Godot 导出 Web 版最省事。
  3. 过资源关。把贴图、音频转成浏览器友好格式（WebP / OGG），大文件做分片加载，否则首屏就卡住。
  4. 处理输入与存档。键鼠 + 手柄 + 触屏三套输入，存档走 IndexedDB，别指望 localStorage 装下几十 MB。
  5. 别自己托管受版权保护的资源。只发布运行器，让用户导入自己的正版文件，这条线最安全。
